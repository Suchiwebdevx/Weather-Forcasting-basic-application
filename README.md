🌤️ Weather Application

A simple and responsive Weather Application that allows users to search for a city and view its current weather information in real time.

The application fetches weather data from a weather API and presents important information such as temperature, weather conditions, humidity, and wind speed through a clean and user-friendly interface.

📌 Project Overview

The Weather Application was developed to provide users with quick access to current weather information for different locations.

Users can enter the name of a city, and the application retrieves the latest available weather data through an external weather API.

This project demonstrates the practical use of JavaScript, API integration, asynchronous requests, DOM manipulation, and responsive web design.

🔄 How It Works

The application follows a simple process:

User enters city
       ↓
JavaScript sends API request
       ↓
Weather API processes request
       ↓
Weather data returned as JSON
       ↓
JavaScript processes the response
       ↓
Weather information displayed
🌐 API Integration

The application uses a weather API to retrieve real-time weather information.

The API response provides weather-related data such as:

City
Temperature
Weather Condition
Humidity
Wind Speed

JavaScript processes the JSON response and dynamically updates the webpage.

Note: API keys should not be committed directly to a public GitHub repository. Use environment variables or another secure configuration method when applicable.
